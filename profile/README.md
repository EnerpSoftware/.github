Wszystkie nasze projekty korzystaja z centralnych workflow GitHub Actions.
Automatyzacja obejmuje:
- Build i testy
- Docker build & push do ghcr.io
- Deployment na klaster k3s
- Automatyczne generowanie bugow przy failed testach
